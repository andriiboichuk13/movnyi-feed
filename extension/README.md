# Мовний фід: розширення для Chrome

Пропонує україномовні альтернативи відео на YouTube, а якщо українських немає, то англомовні з кнопкою «Хочу українське». У дитячому режимі ховає російськомовні картки.

Написано на звичайному JavaScript, без збірки: папку можна одразу завантажити в Chrome.

## Як встановити (3 кроки)

1. Відкрийте `chrome://extensions` і ввімкніть «Режим розробника» (перемикач праворуч угорі).
2. Натисніть «Завантажити розпаковане» і виберіть цю папку (ту, де лежить `manifest.json`).
3. Відкрийте будь-яке відео на YouTube. Праворуч над рекомендаціями з'явиться панель «Мовний фід».

Після будь-якої зміни в коді натисніть кнопку оновлення ↻ на картці розширення в `chrome://extensions` і перезавантажте вкладку YouTube.

## Що де лежить

| Файл | Що робить |
|---|---|
| `manifest.json` | Опис розширення для Chrome: дозволи, які скрипти де запускати |
| `src/config.js` | **Усі налаштування**: адреса бекенду, заглушка, пороги, ліміти |
| `src/selectors.js` | **Селектори YouTube**. Ламаються першими, коли YouTube змінює верстку |
| `src/lang.js` | Визначення мови на клієнті: літери (і, ї, є, ґ / ы, э, ё, ъ), службові слова (как/як, что/що…) і модель Chrome |
| `src/background.js` | Єдиний, хто ходить на бекенд. Кеш, `installId`, ліміти, події, лічильники |
| `src/api-mock.js` | Заглушка бекенду. Працює, поки `USE_MOCK: true` |
| `src/content/main.js` | Стежить за переходами між відео (YouTube це SPA) і запускає все інше |
| `src/content/panel.js` | Панель альтернатив і кнопка «Хочу українське» |
| `src/content/filter.js` | Дитячий режим: ховає російськомовні картки |
| `src/content/common.js` | Допоміжні функції |
| `src/popup/` | Вікно розширення: перемикачі, дитячий режим, PIN, мовний баланс |
| `tests/lang.test.js` | Тести мовної евристики: `node --test tests/lang.test.js` |

## Як це працює

**Сторінка відео.** `main.js` ловить подію YouTube `yt-navigate-finish`, бере `videoId` з адреси і назву відео. Клієнт швидко оцінює мову за назвою (це лише підказка), а background запитує `GET /alternatives`. Якщо відео українське, панелі немає. Інакше панель показує до 3 альтернатив і рівень драбини фолбеків. Кнопка «Хочу українське» велика на рівнях 4–5 і маленьким посиланням «Це не те» на рівнях 1–3.

**Дитячий режим.** `filter.js` стежить за появою карток через `MutationObserver`. Для кожної картки: спершу літери в назві (миттєво), потім модель Chrome, а невпевнені картки пачкою до 50 штук ідуть на `POST /classify`. Ховаємо лише `ru` з впевненістю ≥ 0.8 через CSS-клас `mf-hidden`, вузли не видаляємо. `unknown` завжди лишається видимим.

**Приватність.** `installId` це випадковий UUID. Події не містять назв відео. У дитячому режимі події не надсилаються, текстового поля в «Хочу українське» немає, а лічильник прихованого зберігається локально і йде на сервер лише як денна сума і лише з дозволу батьків.

## Контракт з бекендом

Перші три ендпоінти взяті з ТЗ. Формати `/classify` і денної суми в ТЗ не описані, їх треба погодити з бекендом.

**`GET /alternatives?videoId=…&mode=default|kids`**
```json
{
  "source": { "lang": "ru", "confidence": 0.93 },
  "level": 1,
  "items": [
    { "videoId": "xxxxxxxxxxx", "title": "…", "channel": "…", "lang": "uk", "hasUkDub": false, "score": 0.87 }
  ]
}
```
`level` від 1 до 5 за драбиною з ТЗ. На рівні 5 `items` порожній. Необов'язкове поле `thumbnail` в item, інакше береться `i.ytimg.com/vi/<id>/mqdefault.jpg`.

**`POST /classify`** *(погодити)*
```json
// запит
{ "videoIds": ["id1", "id2"] }
// відповідь
{ "results": { "id1": { "lang": "ru", "confidence": 0.91, "source": "defaultAudioLanguage" } } }
```

**`POST /wish`**
```json
{ "installId": "uuid", "videoId": "…", "videoTitle": "…", "level": 4, "userText": "до 280 символів або null" }
```

**`POST /events`**
```json
{ "installId": "uuid", "type": "panel_shown | alt_clicked | wish_sent", "level": 2, "ts": "ISO-час" }
```
Денна сума дитячого режиму *(погодити)*: той самий `/events` з `"type": "kids_hidden_daily", "count": 37, "date": "2026-11-14"`.

Розширення робить запити з background, тому CORS для нього на бекенді налаштовувати не треба. Для сайту `/try` CORS потрібен.

## Як підключити справжній бекенд

1. У `src/config.js` поставте `API_BASE` (наприклад, `https://movnyi-feed.onrender.com`) і `USE_MOCK: false`.
2. Якщо домен не `*.onrender.com` і не `*.up.railway.app`, додайте його в `host_permissions` у `manifest.json`.
3. Оновіть розширення в `chrome://extensions`.

## Бекенд на власному ноутбуці

Лише для себе: запустіть бекенд на порту 8000 і поставте `API_BASE: "http://localhost:8000"`, `USE_MOCK: false`.

Щоб розширення працювало в тестувальників: запустіть `ngrok http 8000` і поставте в `API_BASE` адресу, яку покаже ngrok (`https://….ngrok-free.app`). Адреса безкоштовного ngrok постійна, тому міняти її в конфігу після перезапуску не треба. Заголовок, що прибирає сторінку-попередження ngrok, розширення вже додає саме.

Ноутбук має бути ввімкнений і не спати, інакше в усіх розширення мовчки перестане показувати альтернативи.

## Перевірка селекторів (15.11 за планом)

Відкрийте YouTube, F12 → Elements → Ctrl+F і по черзі вставте селектори з `src/selectors.js`. Для кожної групи має знайтися хоча б один. Якщо ні, знайдіть новий елемент і додайте його селектор **на початок** відповідного списку.

Найважливіші: `ytd-rich-item-renderer` (картки на головній), `#secondary-inner` (куди вставляється панель), посилання з `/watch?v=` усередині картки.

## Як шукати помилки

Перше, що треба зробити: оновити вкладку YouTube (F5). Chrome не запускає розширення у вкладках, відкритих до його встановлення чи оновлення. Popup сам підкаже, якщо на поточній вкладці розширення не працює.

Якщо все працює, у консолі вкладки є рядок «[Мовний фід] запущено на цій вкладці», а для кожного відео рядок з назвою, мовою за клієнтом і бекендом та рівнем драбини.

Логи content script: F12 на вкладці YouTube → Console, рядки з «[Мовний фід]». Логи background: `chrome://extensions` → картка розширення → «service worker» → Console. У режимі заглушки там видно, які `/wish` і `/events` надіслалися б.

## ZIP для журі

Запакуйте вміст цієї папки (без `tests/` і `README.md` за бажанням) у zip. Журі розпаковує його і встановлює за трьома кроками вище.

## Відомі обмеження

Дитячу фільтрацію можна обійти, вимкнувши розширення в `chrome://extensions`: PIN захищає лише перемикач у popup. Приховування елементів YouTube може суперечити правилам YouTube API (див. розділ Legal у ТЗ). Якщо YouTube змінить верстку, оновлюємо `selectors.js`.
