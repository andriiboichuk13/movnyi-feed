# Мовний фід: як спробувати обійти систему

Це інструкція тестувальника: **як звичайна людина (або дитина) може випадково чи навмисно обійти розширення, не ламаючи нічого «по-хакерськи»**. Мета не показати, що система погана, а знати межі: що вона реально гарантує, а що ні, і чесно сказати це батькам, журі й собі.

## Правила гри

Робимо лише те, що може зробити будь-хто, хто просто користується браузером і YouTube:
- Лише свій акаунт, свій браузер, свій пристрій.
- **Не** атакуємо сервер: жодних сканерів, автоматичних масових запитів, підбору чужих `installId`, спроб дістатися до бази чи ключів. Для експериментів із сервером використовуйте тестовий бекенд (`tests/tools/mock-backend.py`), а на Railway лише ручні одиничні дії.
- DevTools і `chrome://extensions` це теж «звичайне користування»: дитина, яка вміє F12, їх знайде.

**Як фіксувати.** Для кожного пункту дві відповіді: *Утримало* (система зробила те, що обіцяє) або *Обійдено* (російське показано, українське сховано, захист знято, надіслано зайве). Колонка «Прогноз» це висновок з коду й автотестів; ваша задача підтвердити або спростувати його на справжньому YouTube.

```
ID | Прогноз | Фактично (Утримало / Обійдено) | Що саме побачили | Скріншот/відео
```

## Підготовка

1. Встановіть розширення (`TESTING.md`, розділ 2), увімкніть **дитячий режим**, встановіть PIN `4821`.
2. Режим B (мок-бекенд) для керованих перевірок, режим C (Railway) для реальних відео.
3. У консолі YouTube тримайте `feed-report.console.js`: він показує, що з кожною карткою зробило розширення.
4. Щоб мати «справжнє російське відео», яке розширення не розпізнає за літерами, візьміть будь-яке російськомовне відео з **нейтральною назвою** (без ы, э, ё, ъ й слів «как/что/это») і примусьте мок-бекенд: `http://localhost:8000/__set?ru=<videoId>`.

| A1-3 | Пошук російською запитом | Утримає у старій верстці, **може обійтися у новій** (`yt-lockup-view-model`); перевірте, яку верстку бачите |

### A5. Обман евристики мови

Мова визначається за літерами й словами в назві; якщо не впевнено, питаємо сервер; якщо і він не знає, відео **лишається видимим**. Спробуйте знайти (або змоделювати мок-бекендом) такі випадки:

| ID | Спроба | Прогноз |
|---|---|---|
| A5-1 | Російське відео з **нейтральною** назвою («Ремонт ноутбука») | Видно, поки сервер не відповів; ховається лише якщо сервер знає мову. Заміряйте, скільки секунд воно було на екрані |
| A5-2 | Російська назва латиницею («Kak zarabotat million») | **Обійдено**: Cyrillic-евристика не працює |
| A5-3 | Назва лише з емодзі й цифр («🔥 TOP 10 🔥») | Обійдено, залежить від сервера (аудіо-мітка) |
| A5-4 | Російське відео з однією «і» чи «ї» в назві або каналі | Може вважатись змішаним (`unknown`) і лишитись видимим |
| A5-5 | Російське відео з **українською назвою** (автор переклав лише назву) | **Обійдено** (перевірено): клієнт упевнено вирішує `uk` і на сервер не питає взагалі |
| A5-6 | **Автопереклад назв YouTube**: поставте мову інтерфейсу YouTube українською і знайдіть російське відео, у якого є перекладена назва. Чи бачите українську назву на російському відео? | Якщо так: **Обійдено** (розширення читає назву з DOM, а не оригінальну) |
| A5-7 | Розширення для підміни назв (DeArrow тощо) | Може змінити назви в DOM і збити визначення |
| A5-8 | Україномовне відео, яке **хибно** ховається («Моя перша зарплата»): знайти ще такі | Це не обхід, а хибне спрацювання, але для дитини теж проблема. Записуйте назви, їх можна додати в корпус `lang.corpus.test.js` |
| A5-9 | Відео болгарською/сербською | Болгарська з «ъ» ховається як російська |

## Що з цим робити (коротко)

| Знахідка | Ідея виправлення |
|---|---|
| Поверхні без покриття, автовідтворення | Додати селектори (`selectors.js`); для автовідтворення вимкнути його кнопкою/через `yt-navigate`; чесно написати, що перегляд не блокується |
| Вимкнення в `chrome://extensions`, інкогніто, інші браузери | Це межа розширення. Для реального захисту: керований профіль / Family Link / політика, а розширення розглядати як «фільтр стрічки», не як батьківський контроль |
| Слабкий PIN | Сіль + повільний хеш (PBKDF2), затримка після 5 помилок. Нічого з цього не зупинить DevTools |
| fail-open при недоступному сервері | Для дитячого режиму розглянути «ховати нейтральні, поки сервер не відповів» (fail-closed) як опцію |
| `/actions hid` без дозволу | Перевірка `shareKidsStats` у `handleVideoActions` |
| Глобальна квота YouTube | Ліміт на `installId` для викликів, що тратять пошук; кеш; `debug` лише за ключем |
| Автопереклад назв | Брати мову не лише з назви: питати сервер для всіх карток, де мову визначили лише за назвою |
