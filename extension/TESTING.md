# Мовний фід: тестування

Див. також **[BYPASS.md](BYPASS.md)**: інструкції, як спробувати обійти систему під час звичайного користування.

Усе, що потрібно тестувальнику: як встановити, як перевірити, що працює, що робити, коли ні, і де вже знайдені проблеми.

## 0. Що саме робить розширення (щоб знати, що перевіряти)

Це важливо, бо з назви проєкту можна подумати інакше:

| Режим | Що відбувається |
|---|---|
| **Звичайний** (за замовчуванням) | Російськомовні відео **не ховаються**. На сторінці відео, якщо воно не українське, зʼявляється панель з україномовними альтернативами. |
| **Дитячий режим** | Російськомовні картки **ховаються** на головній (FYP), у рекомендаціях збоку й у пошуку. Ховається лише `ru` з упевненістю ≥ 0.8, `unknown` завжди лишається видимим. |

Тобто «прибирання російського з FYP» працює лише з увімкненим дитячим режимом. Тестувати це треба саме там.

**Нове в цій версії (є в тестах):** панель зʼявляється одразу із заготовками, якщо розширення само впевнене, що відео не українське, і заповнюється, коли відповість сервер; якщо сервер мовчить, запит повторюється через 3 с і ще через 8 с, а потім показується кнопка «Спробувати ще раз»; таймаут запиту 20 с; на сервері текст важить більше за англійську мітку аудіо (українська назва + `defaultAudioLanguage=en` = українське відео).

## 1. Підготовка

| Що | Для чого |
|---|---|
| Chrome (або Edge/Brave) | розширення MV3 |
| Node.js 20+ | автотести |
| Python 3.9+ | тестовий бекенд, тести бекенду |

```powershell
cd extension\tests
npm install          # один раз, ставить jsdom
npm test             # ~75 секунд (є тести повтору запиту з реальними паузами), усі автотести
```

Очікуваний результат: `fail 0`. Рядки `todo` це відомі проблеми (розділ 8), вони не валять запуск.

Тести бекенду (база й ключі не потрібні, YouTube і БД підмінені заглушками):

```powershell
pip install pytest fastapi httpx numpy pgvector "psycopg[binary]" psycopg_pool python-dotenv requests
cd backend
python -m pytest tests -v
```
Без `fastapi` тести справжнього сервера пропускаються, тести мови працюють з одним `pytest`.

## 2. Як встановити розширення

1. Розпакуйте проєкт. Потрібна папка, де лежить `manifest.json` (це `extension`).
2. Chrome → адреса `chrome://extensions`.
3. Угорі праворуч увімкніть **«Режим розробника»**.
4. **«Завантажити розпаковане»** → виберіть папку `extension`.
5. Закріпіть іконку (пазл у тулбарі → шпилька).

**Як зрозуміти, що встановилось нормально:**
- Картка «Мовний фід» без червоної кнопки **«Помилки»**.
- Є посилання «service worker». Натисніть його: відкриється консоль background, там не має бути червоного.
- Відкрийте YouTube, F12 → Console: є рядок `[Мовний фід] запущено на цій вкладці`.

> **Головне правило:** після встановлення або оновлення розширення (↻ на картці) **обовʼязково F5 у вкладці YouTube**. Chrome не запускає розширення у вкладках, які були відкриті раніше. Popup сам підкаже це жовтою плашкою.

## 3. Три режими бекенду

Змінюється в `extension/src/config.js` (після зміни: ↻ у `chrome://extensions` + F5 на YouTube).

| Режим | Налаштування | Коли |
|---|---|---|
| **A. Заглушка** | `USE_MOCK: true` | Бекенду немає. Видно всі 5 рівнів панелі, але мова береться лише з клієнта і нічого не ховається за бекендом. У панелі й popup буде напис «Демо-дані». |
| **B. Тестовий бекенд** (рекомендовано) | `USE_MOCK: false`, `API_BASE: "http://localhost:8000"`, запустити `python tests/tools/mock-backend.py` | Повний контроль: самі кажете, яке відео російське, і бачите кожен запит. Без Supabase і ключа YouTube. |
| **C. Справжній бекенд (Railway)** | `USE_MOCK: false`, `API_BASE: "https://movnyi-feed-production.up.railway.app"` (так зараз у `config.js`) | Фінальна перевірка на справжніх даних. Перший запит після простою повільний (холодний старт), тому на ньому видно заготовки й повтори. Не робіть автоматичних навантажень на цей сервер. |

### Тестовий бекенд (режим B)

```powershell
cd extension
python tests\tools\mock-backend.py          # порт 8000
```

Він друкує кожен запит з тілом (так перевіряється приватність) і керується посиланнями у браузері:

| Посилання | Дія |
|---|---|
| `http://localhost:8000/__set?ru=ID1,ID2` | ці відео вважати російськими (для `/classify` і `/alternatives`) |
| `…/__set?uk=ID3` | ці відео вважати українськими |
| `…/__set?level=4` | завжди віддавати рівень 4 (`auto` повертає за id) |
| `…/__set?fail=alternatives:500` | зламати ендпоінт (`500`, `429`, `timeout`; `fail=off` прибирає) |
| `…/__set?fail=alternatives:500:2` | зламати лише перші 2 запити, далі працює (для перевірки повтору) |
| `…/__set?delay=3000` | затримка відповіді, мс |
| `…/__state` | що надійшло: wishes, events, actions |
| `…/__reset` | скинути все |

## 4. Інструменти для консолі (F12 на youtube.com)

| Файл | Що робить |
|---|---|
| `tests/tools/selectors-check.console.js` | Перевіряє всі селектори з `selectors.js` на живій сторінці, показує таблицю OK / НЕ ЗНАЙДЕНО. **Запускайте на головній, на сторінці відео і в пошуку.** Перша точка поломки, коли YouTube міняє верстку. |
| `tests/tools/feed-report.console.js` | Таблиця всіх карток стрічки: назва, videoId, `shown/masked/hidden`, мова. Друкує готове посилання `__set?ru=…` для мок-бекенду. |

Використання: відкрити файл, скопіювати весь вміст, вставити в консоль, Enter. Після зміни `selectors.js` перегенеруйте: `node tests/tools/build-selectors-check.js` (автотест нагадає, якщо забули).

Перед кожним блоком чистий стан: у консолі service worker виконайте `chrome.storage.local.clear()`, ↻ розширення, F5 на YouTube. Режим B, увімкнений мок-бекенд.

| I-2 | Встановити при відкритій вкладці YouTube, не оновлюючи її, відкрити popup | Жовта плашка «Оновіть вкладку…» |

### 5.2 Панель альтернатив (звичайний режим)

| ID | Кроки | Очікується |
|---|---|---|
| P-1 | Відкрити відео, `__set?ru=<id>&level=1` | Праворуч над рекомендаціями панель «Мовний фід», «Це відео російською», до 3 карток, маленьке посилання «Не те, що шукали?» |
| P-2 | Рівні 2 і 3 (`level=2`, `level=3`) | Інший підпис рівня, посилання те саме |
| P-3 | `level=4` | «Українською не знайшли. Англійською…», велика кнопка «Хочу українське», тег «Англійською», перше відео з дубляжем має тег «Є український дубляж» |
| P-4 | `level=5` | Лише «поки нічого не знайшли» і велика кнопка |
| P-5 | `__set?uk=<id>` для відкритого відео | Панелі **немає** |
| P-6 | Клік на альтернативу | Перехід на відео без перезавантаження сторінки; у логу мок-бекенду `events alt_clicked` |
| P-7 | Хрестик × | Панель зникає і не повертається для цього відео; на іншому відео зʼявляється знову |
| P-8 | Перейти між відео кліками (SPA) | Панель кожного разу для нового відео, не дублюється, стара не лишається |
| P-9 | Швидко клікнути 3 відео підряд, `delay=2000` | Лишається панель лише для останнього |
| P-10 | Тема YouTube світла і темна | Панель читається в обох |
| P-11 | «Хочу українське» (звичайний режим) | Поле до 280 символів, лічильник, «Скасувати» працює, відправка дає «Запит збережено», у `__state` зʼявляється wish |
| P-12 | У полі натиснути пробіл, `k`, `f`, цифри | Відео не ставиться на паузу й не перемикається |
| P-13 | Надіслати 20 запитів, далі 21-й | «На сьогодні запитів досить» (локальний ліміт) |
| P-14 | Popup → вимкнути «Показувати альтернативи» | Панель зникає без перезавантаження |
| P-15 | Відео з російською назвою (літери ы/э або слово «что»), `__set?delay=3000` | Панель зʼявляється **одразу** із заготовками («Шукаємо українські альтернативи…», 3 сірі рядки) і текстом «Це відео російською»; через ~3 с заготовки замінюються справжніми, без стрибка й без другої панелі |
| P-16 | `fail=alternatives:500:1`, відкрити російське відео | Заготовки ~3 с, потім результати (повтор спрацював) |
| P-17 | `fail=alternatives:500:2` | Результати зʼявляються приблизно через 11 с (3 + 8) |
| P-18 | `fail=alternatives:500` (постійно) | Через ~11 с «Не вдалося завантажити альтернативи» і кнопка «Спробувати ще раз»; після `fail=off` кнопка працює |
| P-19 | Те саме, але з нейтральною назвою («Ремонт ноутбука») | Нічого не показується, жодного повідомлення про помилку |
| P-20 | Під час заготовок натиснути × | Панель не повертається, коли приходить відповідь |
| P-21 | Під час заготовок перейти на інше відео | На екрані лише панель нового відео, стара відповідь її не перезаписує |
| P-22 | Сервер Railway «сонний»: перше відкриття після простою (режим C) | Заготовки замість порожнього місця; заміряйте час до результату. Найгірший випадок до повідомлення про помилку: 3 спроби × 20 с + 11 с очікування = **~71 с**, це довго |
| P-23 | Україномовний канал, у якого мітка аудіо `en` (режим C) | Панелі немає (сервер за текстом вважає відео українським) |

### 5.3 Дитячий режим (прибирання російського з FYP)

Підготовка: popup → увімкнути «Дитячий режим». Відкрити головну, у консолі виконати `feed-report.console.js`, скопіювати посилання `__set?ru=…`, відкрити його, F5.

| ID | Кроки | Очікується |
|---|---|---|
| K-1 | Головна з російськими назвами (літери ы, э, ё, ъ або слова «как», «что») | Картка стає сірою плиткою «Приховано дитячим режимом», розмір той самий, дірок немає |
| K-2 | Українські й англійські відео | Лишаються видимими |
| K-3 | Російське відео з нейтральною назвою («Ремонт ноутбука»), `__set?ru=<id>` | Спершу видно, за ~0.5 с ховається (пішов `/classify`) |
| K-4 | Нейтральна назва, мок-бекенд не знає id | Лишається видимою (`unknown` не ховаємо) |
| K-5 | Прокрутити головну вниз | Нові картки теж фільтруються |
| K-6 | Сторінка відео: рекомендації збоку | Російські зникають повністю, без заглушок |
| K-7 | Пошук | Російські результати зникають |
| K-8 | Shorts на головній | Російські Shorts ховаються так само |
| K-9 | Вимкнути дитячий режим | Усі картки повертаються без перезавантаження |
| K-10 | `fail=classify:500` | Нічого не ховається зайвого, нічого не ламається |
| K-11 | Лічильник у popup | «приховано сьогодні» росте, за 7 днів не менше |
| K-12 | Встановити PIN `4821`, вимкнути режим | Просить PIN, неправильний не вимикає, правильний вимикає |
| K-13 | PIN < 4 або > 8 цифр, літери | Помилка, PIN не зберігається |
| K-14 | У дитячому режимі «Хочу українське» | Поля тексту немає, кнопка одразу шле запит з `userText: null` |
| K-15 | **Обхід:** вимкнути розширення в `chrome://extensions` | Фільтр знімається (відома межа, PIN захищає лише popup) |

### 5.4 Приватність (дивимось у консоль мок-бекенду або F12 → Network у service worker)

| ID | Перевірка | Очікується |
|---|---|---|
| S-1 | Подія `panel_shown` / `alt_clicked` / `wish_sent` | Лише `installId, type, level, ts`, без назв і id відео |
| S-2 | У дитячому режимі | Подій `/events` немає; текст у wish `null` |
| S-3 | `shareKidsStats` вимкнено | `kids_hidden_daily` не надсилається; увімкнено: лише `count` і `date` |
| S-4 | **У дитячому режимі стежити за `/actions`** | Зараз іде `hid` з videoId незалежно від дозволу, див. розділ 8, пункт P1 |
| S-5 | `installId` | Випадковий UUID, жодного акаунта |

### 5.5 Стійкість

| ID | Кроки | Очікується |
|---|---|---|
| R-1 | Вимкнути мок-бекенд | YouTube працює нормально, панелі немає, у консолі `alternatives: …` |
| R-2 | Увімкнути знову, перейти на нове відео | Працює без перезавантаження розширення |
| R-3 | Вимкнути Wi-Fi | Те саме, жодних помилок для користувача |
| R-4 | Залишити вкладку на 5+ хвилин (service worker засне), перейти на нове відео | Все працює (стан зберігається в storage) |
| R-5 | Оновити розширення (↻) без F5 на вкладці | У консолі вкладки помилки «Extension context invalidated» це нормально, після F5 минає |
| R-6 | Режим інкогніто | За замовчуванням розширення вимкнене; увімкнути в деталях розширення |
| R-7 | `m.youtube.com`, `music.youtube.com`, вбудовані відео | Не підтримуються за дизайном (лише `www.youtube.com`) |
| R-8 | Інша мова інтерфейсу YouTube (англійська, польська) | Фільтр і панель працюють однаково (мова береться з назви відео) |
| R-9 | Повільний ноутбук, довга стрічка (скрол 5+ екранів) | Без помітних гальм і мерехтіння |

Додати випадок до мовного корпусу: рядок у `CORPUS` у `lang.corpus.test.js`. Якщо знайшли помилку, яку ще не виправили, додайте її третім елементом-причиною, і тест стане `todo`.

Спершу завжди: **↻ на картці розширення, потім F5 на YouTube**, і подивитись консоль вкладки (рядки `[Мовний фід]`) та консоль service worker.

## 8. Знахідки автотестів (на стан другого архіву)

Пріоритети: **P1** блокує обіцянку продукту, **P2** помітний недолік, **P3** косметика. Усе це видно в `npm test` як `todo` / в `pytest` як `xfail`.

**P1. Українське відео ховається як російське** («Моя перша зарплата»). Слово «моя» є і в `RU_WORDS`, і в живій українській. Та сама помилка в `backend/lang.py`. Виправлення: прибрати «моя», «твоя» зі списку російських слів, і в клієнті, і на сервері.

**P1. Приватність: id прихованих відео йдуть на сервер без дозволу батьків.** README обіцяє «у дитячому режимі лише денна сума і лише з дозволу батьків», але `filter.js` шле `/actions {action:"hid", videoId}` завжди. Рішення команди: перевіряти `shareKidsStats` у `handleVideoActions` або чесно описати в README і на сторінці конфіденційності.

**P2. Дитячий режим покриває три поверхні з багатьох** (`coverage.test.js`): головна, рекомендації збоку, стара верстка пошуку. Не покрито: нова верстка пошуку, підписки, сторінка каналу, історія, тренди, плейлисти, Shorts-полиця. Фікстури наближені до реальних, тому перевірте кожну поверхню скриптом `selectors-check.console.js` на живому YouTube. Додатково фільтр не блокує перегляд: автовідтворення, кінцеві заставки й пряме посилання обходять його (див. `BYPASS.md`).

**P2. PIN слабкий.** Хеш SHA-256(installId:pin) без солі, `installId` лежить поруч: 4-значний PIN підбирається за ~26 мс. Ліміту спроб немає. Це «захист від дитини, яка не відкриває DevTools», не більше.

**P2. Холодний старт сервера = до ~71 с до повідомлення про помилку** (3 спроби × 20 с таймауту + 3 с + 8 с). Заготовки це пом'якшують, але краще скоротити таймаут повторних спроб (наприклад 8 с) або показувати «сервер прокидається».

**P2. Ліміт «Хочу українське» показується як помилка.** `server.py` віддає HTTP 429, а `apiFetch` кидає виняток на будь-який не-2xx, тож панель каже «Не вдалося зберегти» замість «Запитів досить». Тест `test_real_server_contract.py` підтверджує, що сервер справді віддає 429.

**P2. Подвійні кліки «Надіслати» шлють дублікати.** Три швидкі кліки дають три `/wish` (виміряно): три рядки в базі й три одиниці добового ліміту. Потрібен прапорець «надсилається» на час запиту.

**P2. Змішані літери: «Я і ты» → ru.** `quick()` після `letters-mixed` все одно йде в слова.

**P2. Болгарська та ін. з «ъ» вважаються російськими.**

**P3. Одна українська літера в англійській назві** («Top 10 їжак facts», аудіо en) дає `uk 0.85`, а поріг нового правила «текст над аудіо» теж 0.85, тож відео вважається українським і панель не показується. Підніміть поріг до 0.9 або вимагайте ≥ 2 українських літер.

**P3.** `videoTitle` не обрізається до 300 символів перед `/wish` (YouTube обмежує 100, тож у житті не стається). `popup.js` містить скопійовані блоки `checkActiveTab`. `/alternatives?debug=true` відкритий усім без ключа і віддає внутрішні цифри та назви кандидатів.

**P3. Готовність до здачі** (`RELEASE=1 npm test` робить обовʼязковими): `WEBSITE_URL` це `https://example.com`; `localhost` у `host_permissions`; `main.js` пише назву відео в консоль сторінки. `API_BASE` уже на Railway.

**Питання до продукту:** якщо мета прибирати російське з FYP для всіх, а не лише в дитячому режимі, то зараз цього немає в коді.
